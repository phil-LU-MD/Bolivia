Se filtra el departamento de Oruro y se calcula el porcentaje de voto nulo en cada mesa.

Click to expand code 
oruro_voto_nulo <- resultados_bol25_primeravuelta %>%
  filter(NombreDepartamento == "Oruro") %>%
  filter(Descripcion == "PRESIDENTE") %>% 
  mutate(PorcentajeNulo = round((TotalVotoNulo / VotoEmitidoReal) * 100,0)) %>% 
  #filter(PorcentajeNulo >= 50) %>% 
  arrange(desc(PorcentajeNulo)) %>% 
  #mutate(Clasificacion = row_number()) %>% 
  #select(Clasificacion, everything()) %>% #datatable automatically includes ranking
  select(
    #Clasificacion,
    PorcentajeNulo,
    CodigoCircunscripcionU,
    NombreProvincia,
    NombreMunicipio,
    NombreLocalidad,
    NombreRecinto,
    InscritosHabilitados,
    VotoEmitidoReal
  )
datatable(oruro_voto_nulo)



Diferencia de voto entre Libre y PDC en cada mesa del departamento de Oruro

Click to expand code 
oruro_diflibre_PDC <- resultados_bol25_primeravuelta %>%
  filter(NombreDepartamento == "Oruro") %>%
  filter(Descripcion == "PRESIDENTE") %>% 
  mutate(Diferencia = Voto10 - Voto5) %>% 
  arrange(desc(Diferencia)) %>% 
  select(
    Diferencia,
    NombreProvincia,
    NombreMunicipio,
    NombreLocalidad,
    NombreRecinto,
    InscritosHabilitados,
    CodigoCircunscripcionU
  )

Un valor positivo en la columna Diferencia indica los votos que PDC obtuvo de más respecto a Libre. Asimismo, un valor negativo indica los votos que Libre obtuvo de más respecto a PDC.

datatable(oruro_diflibre_PDC)

Mesas donde la diferencia es lo más ajustada

Click to expand code 
oruro_diflibre_PDC_ajustado <- resultados_bol25_primeravuelta %>%
  filter(NombreDepartamento == "Oruro") %>%
  filter(Descripcion == "PRESIDENTE") %>% 
  mutate(Diferencia = Voto10 - Voto5) %>% 
  filter(Diferencia >= -10 & Diferencia <= 10) %>% 
  arrange(desc(Diferencia)) %>% 
  select(
    Diferencia,
    NombreProvincia,
    NombreMunicipio,
    NombreLocalidad,
    NombreRecinto,
    InscritosHabilitados,
    CodigoCircunscripcionU
  )

En el 8,5 % de las mesas del departamento de Oruro, la diferencia entre Libre y PDC es igual o inferior a 10 votos.

datatable(oruro_diflibre_PDC_ajustado)
